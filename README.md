# Drift – Men's Fashion Store (React Native + Expo)

E-commerce mobile app for men's fashion: hoodies, jackets, t-shirts, shirts, shoes, watches, perfumes and more.

## Features
- Splash screen with app logo
- Email/password login and registration (Firebase Authentication)
- Orders and customer details saved in Firebase Firestore
- Navigation: Drawer, Bottom Tabs, Top Tabs and Stack
- UI library: React Native Paper
- Favorites (heart icon), search, filters (price, color, brand, size, offers)
- Cart, order placement, order history with cancel option
- Profile screen with editable details and logout
- Delivery check by PIN code

## External APIs
- mock.shop: https://mock.shop/api
- FakeStore API: https://fakestoreapi.com/products
- DummyJSON: https://dummyjson.com/products?limit=0
- India Post PIN Code API: https://api.postalpincode.in/pincode/{PIN}

## Screens
Splash, Login/Register, Home, Product Details, Favorites, Cart, Orders, Profile
